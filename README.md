that anyone can read and implement. Each entry links to the specification
itself (or its official home page) and names the body that maintains it.

## Contributing

Contributions are always welcome. To suggest a standard, open a pull request
that adds one row to the table of the most fitting category.

- **It must be an open standard.** The specification is publicly available
  (some, such as ISO standards, may be sold) and anyone may implement it. Software projects and libraries (for example
  OpenSSL) belong in other lists; link the protocol or format they implement.
- **Link the specification itself**, or its official home page, rather than a
  tutorial, blog post or encyclopedia article.
- **Fill in all three columns**: the standard's name, the body that maintains
  it (with the document number where there is one) and a one-sentence
  description.
- **Keep each table in alphabetical order.**
- **Regenerate the overview and index** with `python3 scripts/build_index.py`.
  Don't edit them by hand; the script builds both from the tables.
- CI lints the Markdown, checks every link and verifies that the overview and
  index are up to date, so make sure all three pass.
