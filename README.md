## Contributing

Contributions are always welcome. To suggest a standard, open a pull request
that adds one row to the table of the most fitting category.

- **It must be an open standard.** The specification is publicly readable and
  anyone may implement it. Software projects and libraries (for example
  OpenSSL) belong in other lists; link the protocol or format they implement.
- **Link the specification itself**, or its official home page, rather than a
  tutorial, blog post or encyclopedia article.
- **Fill in all three columns**: the standard's name, the body that maintains
  it (with the document number where there is one) and a one-sentence
  description.
- **Keep each table in alphabetical order.**
- CI lints the Markdown and checks every link, so make sure both pass.
